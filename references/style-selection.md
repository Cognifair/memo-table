# 按材料结构选择样式

选型分两层：先看是否能直接保真表达或通过合理布局适配实现，再看布局与强调是否适合。圆角墨墨简约风是可调整的通用兜底；②③④按固定模板判断，不能将同样限制套在圆角风格上。这里的推荐是排版判断，不是医学、财务等内容正确性验收。

## 先读什么

- 结构：列数、单层/多级表头、横向/纵向合并、分组与小计、续表关系。空白不自动等于上行合并，先依据原图或明确结构标记判断。
- 语义：列的真实含义；末行是否总计，首行是否应突出，数值之间是否存在趋势或差值关系。
- 密度：最长单元格、长短文本混排、列宽差异；结合目标宽度与阅读设备判断，不设“超过某字数就一律拒绝”的阈值。
- 特殊内容：图片、公式、脚注、纵排等。现有字符串字段只保证文本，不等于能渲染图片、公式或富文本。

信息不足时写“暂定：需核对合并/表头关系”。只补问影响排版的缺项，不重新要求用户说明已经明确的输出类型。

## 标签含义

- **推荐**：可保真表达，字段语义与视觉强调相符，预期可读。圆角版需要正常布局适配时可标“推荐兜底，需布局适配”，同时说明不是当前 JSON 直接支持。
- **有条件推荐**：宽度、文本密度或突出效果存在风险，或适配可行性仍待验证；明确条件并用实际数据预览验证。保留关系的圆角版排版适配可直接进行；改变合并语义、字段或顺序的方案须先确认。
- **不推荐**：现有结构无法保真、必须丢信息/伪造字段，或固定装饰会显著误导阅读。说明是“不支持结构”还是“视觉不合适”，并给替代路径。

不要为凑出一个推荐而保证可行；也不要仅因为材料不是销售行业，就排除本来字段语义相容的列表。

## 六种现有输出的判断依据

| 样式 | 推荐的材料 | 不推荐或需检查的情形 |
|---|---|---|
| ① `rounded` 圆角 | 普通知识表可直接使用；合并表、多级表头、长文本等优先作为通用兜底，可保留简约配色并调整布局 | 当前 JSON 不支持真正的合并和多级表头，需另做非锁定适配，而非自动展平。可调整列宽、行高、换行与分页，按需实现合并；图片/公式要另做相应渲染。适配后实际预览验收，不能仅凭风格通用就宣称现有代码支持一切。 |
| ② `table` 产品表格·指标卡 | 恰好序号、项目、日期、金额四列，并且材料中确有两条指标；符合固定表头要求 | 没有日期/金额/两条指标，或要改表头/新增列才能容纳材料时，不推荐现有锁定版。不能把医学定义强行装进日期和金额，不能补造指标。 |
| ③ `comparison` 市场份额对比 | 标签＋三个可比较的短数值＋一个有意义的差值，首行突出与箭头关系符合来源含义 | 不能仅因恰好五列就推荐。无差值语义、分类定义或长段落、复杂合并不适合；首行高亮与箭头不能无端暗示排名或趋势。不为适配而重排来源数据。 |
| ④ `sales` 销售列表 | 每条记录有名称、描述、两个短值、年份与状态，对应六个固定字段 | 普通矩阵、合并分组、多级表头或缺失字段不推荐锁定版；长段文字须检查拥挤。末行固定青绿突出，若来源没有强调最后一项的含义，至少标为有条件推荐并指出误导风险。来源确有空值可保留，不能用空字段掩饰结构不匹配。 |
| ⑤ LaTeX 三线表 | 用户需要代码，且是简短、规则、无合并的矩形表格，内容靠对齐即可区分 | 当前裸 `array` 约定不提供真正的跨行/跨列合并；不把 LaTeX 引擎的一般能力当作本流程已支持。多层分组、长段落、图片不宜；代码检查不等于目标客户端显示已通过。 |
| ⑥ LaTeX 网格表 | 用户需要代码，规则矩形表格中逐格对应关系重要，需要清楚边界 | 同样不自动支持合并、多级表头或复杂媒体；密集网格不代表复杂结构已恢复。过宽或长文本仍需调整/另选图片路线。 |

用户只要 PNG 时，⑤⑥标为“不适用：代码输出”，不用为了推荐而擅自改交付类型；只要 LaTeX 时反之。尚未限定输出类型时比较全部六种。

## 给用户的选型结果

先用一句话概括材料，例如：“这份表有两层表头、纵向合并和长段说明，重点是保留组别对应关系。”随后按编号简短标注适配等级与原因；保留用户可选的非推荐样式，不暗中屏蔽，但不能把不支持的结构承诺为可直接渲染。

②③④不适合时，优先推荐“①圆角墨墨简约风兜底”，必要时注明“需布局适配”，先做保留合并关系、合理列宽与分页的小样。不要仅因当前 JSON 不能表示合并，就把所有风格一并判为不推荐。只有连圆角适配也无法可靠保真，或来源结构缺失时，才说明现阶段无法可靠重制并建议核对材料或保留原图；原图不能称为已按选定样式重制。

圆角布局适配仍属于①，不是必须另选的新样式；保留数据和关系的排版调整无需逐次询问。可能改变含义或结构关系时才确认。适配不意味着当前脚本已经具备相应能力，不声称 JSON 加个 `rowspan` 就已支持；实现后验证，且不修改②③④锁定模板或哈希。

## 批量与验收

- 混合材料至少区分普通矩形、复杂合并/层级、长文本/媒体等实际存在的类型；每类取有代表性的样例，不强求固定分类数。
- 除溢出与透明度，还核对组别归属、跨行跨列范围、表头层级、脚注、图片位置，以及高亮是否引入错误含义。
- 若来源结构丢失，写“待复核”，不能仅凭 PNG 很精美就宣称保真通过。

## 维护时的场景检查

1. 三列定义对照、单层表头、无合并：①可推荐，②③④不能仅为装饰而强套；需要代码时再比较⑤⑥。
2. 五列都是医学概念和长段定义：不能仅按五列推荐③；①也需检查文本密度。
3. 两层表头且左侧纵向合并：优先推荐①兜底并做保留结构的布局适配，不自动扁平化；不声称原有 JSON 已支持。
4. 标签、三个年度比例和差值，短值、首行确为主要对象：③可推荐，不把专业模板一概淘汰。
5. 用户强选④，但来源有跨行分组：说明不支持并确认适配，不静默改①、不改锁定包。
6. 整书大多规则表，少数合并表和图片量表：分别给结论，例外先核对，不能一套样式全书无条件通过。
